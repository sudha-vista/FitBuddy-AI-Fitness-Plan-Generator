# Phase 8 – Project Demonstration

**Project:** FitBuddy – AI Fitness Plan Generator

## 1. Demo Objective

Demonstrate the complete FitBuddy workflow from user input through AI-generated plan, feedback-based revision, database-backed history and API documentation.

## 2. Recommended Demo Sequence

1. Introduce the project name.
2. Explain the problem and purpose.
3. Open the FitBuddy home page.
4. Enter a sample name, user ID, age, weight, goal and intensity.
5. Click Generate 7-Day Plan.
6. Show the original seven-day workout plan.
7. Show the nutrition/recovery tip.
8. Submit feedback such as requesting more cardio or an additional rest day.
9. Show the updated plan.
10. Open the admin dashboard and show stored users/plans.
11. Open /docs and briefly show the REST API documentation.
12. Explain the technologies used and final outcome.

## 3. Voice-Over Points

Project name; purpose; target users; input data; AI generation; database storage; feedback-based revision; admin view; API documentation; testing approach; final output.

## 4. Evidence to Capture

Take screenshots of the home page, generated result, updated result, admin view and /docs page. These can support the GitHub phase documents and demonstration.

## 5. Important Demonstration Check

Run the project before recording. If live Gemini generation is used, verify the configured model ID and API key. If using MOCK_AI, clearly demonstrate that the application flow is being tested with mock responses rather than claiming it is a live Gemini response.

## 6. Submission Requirement

The supplied project instructions require a complete project demonstration video uploaded to Google Drive with a public/anyone-with-the-link viewing setting. The video should include project name, purpose, benefits, working process and final output.
